## What Ghidra-Rare changed

All changes are commits on top of the PR's files, branch `ghidra-rare`:

1. Stand-alone extension build: `Module.manifest`, `build.gradle`, `extension.properties`,
   `LICENSE`, `.gitignore`; the PR's `pic16.ldefs` (which redefined the official PIC-16 and PIC-16F
   languages) became `pic16f153xx.ldefs` with only the 153xx language; the copies of the official
   `pic16f.cspec`/`pic16f.pspec` were dropped.
2. Instruction set and p-code (`pic16.sinc`, `pic16_instructions.sinc`), rebuilt on the data sheet and
   the differential tests:
   - added ASRF, LSLF, LSRF (they decoded as RETLW); RETLW is `0x34xx` only; CLRW accepts its `x` bits;
   - MOVIW sets Z, RLF/RRF no longer set Z, ADDWFC/SUBWFB/SUBWF/SUBLW carry and digit-carry flags
     (DC, like C, is a no-borrow flag after a subtraction), BSR masked to 6 bits;
   - 15-bit program counter: `PCLATH<6:0>` for computed GOTO (`ADDWF PCL`), `MOVWF PCL`, CALLW;
   - PCL reads the address of the next instruction; BRA/BRW/CALL/CALLW/RETURN/RETLW/RETFIE p-code
     (targets were read through code memory, return addresses were byte offsets);
   - `CALL`/`GOTO` targets are direct branches whose page bits come from the context field `pcHi`
     (`MOVLP` sets it for the following instructions; the pspec starts each 2K-word page with its
     own number). The PR computed them from the `PCLATH` register in p-code, which the decompiler
     turned into a jump table (`switch(0x100)`) and, in Ghidra 12.2, failed on;
   - skip instructions branch to `inst_next2` instead of a global `SkipNext` flag (fixes
     NationalSecurityAgency/ghidra#7325, chained skips);
   - an instruction that affects Z/DC/C and has STATUS as destination leaves the flags to the ALU
     (data sheet 4.3.2.1);
   - INTCON and STATUS bit names for the 153xx (the PR used another device's INTCON bits);
   - the assembler pseudo-instructions SKPC/SKPNC/SKPZ/SKPNZ had BTFSC and BTFSS swapped.
3. `pic16f153xx.pspec`/`.cspec` generated by `test/gen_pspec.py` from the data sheet's register summary
   (32 of the 272 hand-typed SFR symbols were wrong), GPR/SFR ranges for 50 banks. The PR's
   `tracked_set` values for PCLATH (512-byte ranges numbered as if the space were 13 bits wide) are
   replaced by a disassembly context, below.
4. `README.md`, `GHIDRA-RARE.md`, this file, `test/` (emulator cases, differential tests, real-code
   checks).
